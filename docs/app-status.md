# OUTREPD — حالة التطبيق

آخر تحديث: 17 أغسطس 2026. الفرع `camera-rep-counter`، و55 اختبار بيعدّوا.

## اللي خلص

**الثيم** — دارك ولايت، بيتبدّل فورًا في كل الشاشات. الألوان بتتقرا من الـ
ThemeData مش من متغير عام، وده اللي بيخلي التبديل يوصل للشاشات المفتوحة.

**الإعدادات** — صفحة كاملة، 8 أقسام، وكلها بتتحفظ على الجهاز.

**البروفايل** — صورة شخصية (من الموبايل أو أفاتار جاهز) داخل إطار الرتبة،
تعديل الطول والوزن والسن، وتعديل الاسم **مرتين بس** طول عمر الحساب.

**الإطارات** — تسعة، واحد لكل رتبة، بتتغير تلقائيًا بالترقية. فتحة كل إطار
**مقاسة من الشفافية** بـ `D:/outrepd-tools/measure_frames.py` مش بالعين. الأرقام
في `lib/profile_avatar.dart`؛ لو الرسومات اتغيرت شغّل السكريبت تاني.

**الأفاتارات في كل مكان** — الأصدقاء، الكرو، الليدربورد. صورة أي حد تاني
**مشتقة من اسمه بالهاش**، فنفس الشخص بيبان نفس الشكل على كل جهاز.

**المكافآت** — 61 لقب مربوطين بإنجازات، تلبس واحد جنب اسمك. وسلسلة أيام
**بتسامح يومين راحة في الأسبوع** عن قصد: الراحة جزء من التمرين، ولحظة ضياع
الرقم هي لحظة ترك التطبيق.

**الكرو** — من غير كرو: أربع طرق للدخول. بكرو: تبويبين (الكرو / الترتيب)، هدف
أسبوعي، مين شغال بشرايط مقارنة، كل الأعضاء، حرب كرو، ومواسم شهرية.
**الترتيب بمتوسط الفرد** مش المجموع، عشان الكرو الكبير ما يكسبش بالحجم.

**عدّاد العدات بالكاميرا** — شغال؛ التفاصيل في `docs/rep-counter-status.md`.

## راوتات المعاينة

```
#/home #/profile #/awards #/crew #/crewin #/crewrank #/crewnew
#/ranks #/friends #/road #/trainer #/counter #/settings
```

`#/crewin` و`#/crewrank` بيفتحوا وإنت داخل كرو بالفعل — الضغط على الكانفاس في
معاينة الويب مش موثوق، فأي حالة محتاج تشوفها ليها راوت.

## اللي لسه ناقص

1. **فتح الأفاتارات بالإنجازات** — دلوقتي كلهم مفتوحين.
2. **مكافأة نهاية الموسم** — الترتيب بيتصفّر شهريًا بس مفيش مكافأة لسه.
3. **الألقاب اللي محتاجة لحظة** (Clean Hands، Sunrise Club، Giant Slayer)
   مربوطة بـ `rewards.award()` ومحدش بينده عليها لحد ما الماتش والعدّاد
   يوصّلوا نتايج حقيقية.
4. **ألقاب الناس التانية** مش معروضة — محتاجة سيرفر.
5. **شاشات ما اتلمستش**: الإشعارات، ومسار الماتش نفسه
   (`match_entry` / `match_flow`).
6. **شاشة الماتش** لسه واقفة على تلات قرارات في
   `project_outrepd_open_questions`.

## البناء

الأصول والبناء كلهم على قرص D — C ممتلي.

```
export OUTREPD_BUILD_DIR='D:/outrepd-build'
flutter build apk --release     # ثم انسخ لـ Desktop
flutter build web --release     # ثم npx serve -s build/web -l 8080
```

**ابني الاتنين مع بعض** بعد أي تعديل — الويب للمعاينة والـ APK للموبايل.
